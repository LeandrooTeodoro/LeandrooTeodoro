## 🚀 Projeto em destaque

### InovaPulse — Site Institucional Fullstack

> Plataforma completa para empresa de **Automação Inteligente, Robótica e IA Industrial**

[![Status](https://img.shields.io/badge/status-em%20deploy-orange?style=flat)]()
[![Stack](https://img.shields.io/badge/stack-React%20%2B%20FastAPI-blue?style=flat)]()

**O que é:** Site institucional com área do cliente autenticada, blog, formulário de orçamento multi-step e cases de sucesso — tudo integrado via API REST.

| Camada | Tecnologia |
|--------|-----------|
| Frontend | React 18 + Vite + TailwindCSS + Framer Motion |
| Backend | FastAPI (Python) + SQLAlchemy |
| Banco | SQLite (dev) → PostgreSQL (prod) |
| Auth | JWT com bcrypt |
| Animações | Canvas API (rede neural) + Intersection Observer |

**Funcionalidades implementadas:**
- 🎨 Background animado com rede neural em Canvas API
- 🔐 Área do cliente com autenticação JWT completa
- 📋 Dashboard de projetos com barra de progresso
- 🎫 Sistema de tickets de suporte
- 📝 Blog paginado com filtros por categoria
- 💬 Formulário de orçamento em 4 etapas
- 📱 Totalmente responsivo (320px – 1440px)
- 🔍 SEO completo: meta tags, Open Graph, Schema.org
